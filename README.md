## How to install any skill

1. Download the skill's zip. Do not unzip it.
2. In Claude, open **Settings → Capabilities** and turn on **Code execution and file creation**. Then open **Customize → Skills**, click **+**, then **Create skill → Upload a skill**, and choose the zip.
3. If the skill needs a connector (such as Klint), add it in **Customize → Connectors**. The skill's README shows how.
4. Open a new chat and ask for what the skill does.

Each skill's folder has a README with the full steps, what it costs, and an example.

**Packs for Claude Code** (such as the AI Video Factory) install differently: unzip them and follow the prompts in their README.
