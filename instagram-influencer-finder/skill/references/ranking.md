# Merge, filter, and rank

Do these steps in order. Use only what the Klint replies say.

## 1. Merge

- Collect every creator from the 3 replies.
- Use the handle, in lower case and without "@", as the key. The same handle from two or three agents is **one** creator.
- For a creator found by more than one agent, keep all the angles, all the proof posts, and the most complete value of each field.

## 2. Filter (remove the creator if any of these is true)

| Remove if | Why |
|---|---|
| There is no Instagram profile link | We cannot check them |
| There is no proof post link | The fit must show in posts |
| The last post is more than 30 days old, or "posts in last 30 days" is 0 | Inactive |
| The country is not the checkpoint country (when Klint says so) | Wrong market |
| The follower count is outside the checkpoint size band by more than 20% | Wrong size |
| "Adult" is not a clear yes, or anything suggests under 18 | Safety. No exceptions. Proof is a stated age, a job, a degree, marriage, or children. "Professional creator" or "does brand deals" alone is not proof |
| It is the brand's own account, a competitor brand's account, a shop, or a meme or repost page | Not a creator |
| It is on the user's avoid list | The user said so |

If Klint wrote "not checked" for country, size, or last post, keep the creator, but add the gap to their red flags.

## 3. Score

Start each creator at 0.

| Signal | Points |
|---|---|
| Found by 2 angles | +3 |
| Found by all 3 angles | +6 (instead of +3) |
| Mentions the brand without being paid | +4, and tag the card **"Already a fan"** |
| Has done a paid or gifted post for a competitor | +3 |
| Has any sponsored posts in the last 20 (1 or more) | +2 |
| 3 proof posts that clearly match the angle | +2 |
| 2 proof posts that clearly match the angle | +1 |
| Posted in the last 7 days | +1 |
| Likes and comments are visible and look normal or high for the size | +1 |
| Nearly every recent post is an ad (15 or more of the last 20) | −2, and add **"heavy ad load"** to red flags |
| Comments look generic or fake, or likes are very low for the size | −2, and add it to red flags |

Sponsored posts are a **good** sign. They show the creator does deals. Only the extreme case (heavy ad load) takes points away.

## 4. Rank and cut

- Sort by score, highest first.
- Break ties by the stronger proof posts, then by the higher typical likes for the size.
- Keep the top **15 to 25**. If fewer than 15 creators pass the filter, show all of them and say how many passed. **Never add creators to reach 15.**

## 5. Write the fields you add

For each creator in the list, write:

- **Why they fit:** one or two lines that name a **specific pain point or customer trait from the brief**. Not "great engagement". For example: "Posts her son's eczema flare-ups every winter; her followers ask what cream she uses."
- **Best proof post:** the one post link that shows the fit most clearly.

## 6. Tell the user what you found

Before the artifact, give 3 or 4 short lines:

- How many creators each angle found, how many passed the filter, how many are in the list
- The creators tagged "Already a fan" (if any)
- Any angle that failed or returned few creators
- One surprise: a creator or a type of creator the user probably did not expect, from the "Pain" angle if possible
