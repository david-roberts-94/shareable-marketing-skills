# Prompt 2: make the video factory folder

```text
Make a folder called video-factory with three folders inside:
- sources: my raw footage, one file per take (and a separate audio file if my mic records one)
- assets: screenshots, logos, images from the web, and reference Reels
- edit: one folder per video, with its script, its edit plan, and the finished video

Then:
1. Copy the video-script and video-edit skills from the FACTORY pack into video-factory/.claude/skills/.
2. Copy templates/brand-sheet.md from the pack to video-factory/brand-sheet.md.
3. Copy templates/CLAUDE.md from the pack to video-factory/CLAUDE.md.
4. Open video-factory as the project folder from now on.

Show me the folder tree when you're done.
```

## What you should see

```text
video-factory/
  CLAUDE.md          how Claude works in this folder
  brand-sheet.md     your editing style (empty until prompt 3)
  ideas.md           your idea list (made by prompt 4)
  sources/
  assets/
  edit/
  .claude/skills/
    video-script/
    video-edit/
```

In the Claude desktop app, pick **video-factory** as the folder for the Code tab every time you
work on a video.
