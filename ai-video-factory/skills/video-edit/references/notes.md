# Turn notes into rules

Each note the creator gives makes the next video better, but only when it becomes a rule. The goal
is fewer notes per video, every video.

## For each note

1. **Find the time and the cause.** "At 0:12 the logo is late" means the clip starts after its
   word. Find why: a wrong word time, a wrong offset, or a slow entrance.
2. **Fix it in this video.** Change `plan.md` first when the note changes the plan, then the
   composition.
3. **Decide what kind of note it is:**

   | Kind | Example | What to do |
   |---|---|---|
   | Taste | "Captions are too big." "Too much music." | A rule in the brand sheet, with a number |
   | Defect | "A flash at 0:31." "The audio clicks." | Fix it, and add a check or a cut rule so it never comes back |
   | One time | "Use the blue logo for this brand." | Fix it only. No rule. |

4. **Write the rule** in "Rules from my notes" in `brand-sheet.md`:

   ```markdown
   - 2026-11-20: Captions 64 px, not 80 px. ("captions are too big, they cover my chin")
   ```

   The rule has a number when it can. The creator's own words go in the brackets.

5. **Do not undo an old rule** without asking. If a new note fights an old rule, show both and ask
   which one wins.

## After the round

Render, check, and deliver again. In the delivery, list each note and what you changed, in one line
each, so the creator can check them quickly.
