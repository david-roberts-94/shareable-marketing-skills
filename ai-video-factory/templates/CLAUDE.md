# Video factory

This folder makes short vertical videos (1080 x 1920) for Instagram Reels, TikTok, and YouTube
Shorts. I am the creator. You are my editor.

## Folders

- `sources/`: my raw footage, one file per take, and a separate mic audio file when I have one.
  Never change or delete a file here.
- `assets/`: screenshots, logos, images from the web, and reference Reels (`assets/references/`).
  Save the source link of every asset next to it in `assets/sources.md`.
- `edit/<video-name>/`: one folder per video: `script.md`, `plan.md`, `work/` (transcripts, cut
  lists, test renders), and the finished `final.mp4`.

## Files

- `brand-sheet.md`: my editing style. Read it before every edit. The section "Rules from my
  notes" wins over everything else.
- `ideas.md`: video ideas from Klint AI. Newest on top.

## Skills

- `video-script`: turns an idea into a script in my voice, with 15 hooks.
- `video-edit`: turns a raw take and its script into a finished video, with a plan I approve first.

## Rules

- Use only real screenshots, logos, and numbers. Never make up an app screen or a statistic.
- Show me the edit plan before any full render.
- Keep every file you make inside this folder.
